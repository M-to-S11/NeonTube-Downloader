NeonTube Downloader V1.38.0 - WITHOUT VIDEO PLAYER
==================================================

RUN FROM SOURCE (on your computer with Python installed):
  start_windows.bat

CREATE A PORTABLE WINDOWS ZIP (on a Windows build computer with Python):
  PORTABLE_ERSTELLEN.bat

After a successful build, the output is:
  dist\NeonTubeDownloader_Portable_V1.38.0_Windows.zip

Only the ZIP created in the dist folder is the ready-to-use portable
Windows distribution. The target computer does not need Python or VLC.
The source-code archive itself does NOT include a prebuilt Windows EXE.

When sharing the portable application, distribute the FULL folder
contained in the finished ZIP, not just the EXE.

The application stores settings, your API key, favorites, and history
in the current user's profile at:
  %APPDATA%\NeonTubeDownloader

For privacy reasons, any data left over from the old video-player
playlist feature is not automatically deleted.
