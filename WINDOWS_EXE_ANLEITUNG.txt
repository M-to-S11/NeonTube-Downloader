NEONTUBE DOWNLOADER V1.38.0 - PORTABLE WINDOWS
=============================================

THIS SOURCE-CODE ARCHIVE DOES NOT CONTAIN A PREBUILT WINDOWS EXE.

To build the portable package on your own Windows computer:

1. Extract the source-code ZIP.
2. Double-click PORTABLE_ERSTELLEN.bat.
   Python must be installed on the computer used for building.
3. Let the build finish and review any errors shown in the window.
4. The finished ZIP will be saved as:
   dist\NeonTubeDownloader_Portable_V1.38.0_Windows.zip
5. Extract that ZIP on the computer where you want to use the app.
6. Start:
   NeonTubeDownloader\NeonTubeDownloader.exe

The computer running the portable application does not require a
separate Python installation or setup wizard.
This build is intended for Windows 10/11 x64.

IMPORTANT: Keep ALL files from the finished portable ZIP together.
Copying only the EXE out of its folder is not sufficient.

Settings and history are stored at:
  %APPDATA%\NeonTubeDownloader

Because the EXE is unsigned, Windows Smart App Control may block it.
Do not bypass Windows security protections without assessing the risk.
